# Fly Cursor

Небольшое приложение для macOS: муха заменяет обычный указатель, складывает крылья в покое и машет ими при движении. Клики и перетаскивание проходят как обычно.

Для сборки нужны macOS и инструменты командной строки Xcode. Запустите `./build.sh`, затем откройте `build/Fly Cursor.app` в Finder. Если уже запущена другая копия, сначала закройте её через 🪰 в строке меню.

В меню 🪰 можно приостановить эффект, изменить размер мухи, вернуть обычную стрелку или выйти. Скрытие стрелки в фоне использует недокументированный механизм macOS: после обновления системы он может перестать работать.
